# CV Heart & Vascular website

Single-page site for CV Heart & Vascular (Camp Hill and Carlisle, PA). Plain HTML, no build step.

- `index.html`: the page
- `assets/`: logo, heart mark, and the area map (map data: U.S. Census Bureau TIGER/Line, public domain)

Hosted with GitHub Pages from the `main` branch. To change text, edit `index.html` and commit.
